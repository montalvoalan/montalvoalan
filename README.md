### 🎓 Student Success Prediction & Academic Profile Analysis

Built an end-to-end machine learning workflow on 4,424 student records to predict Dropout, Enrolled, and Graduate outcomes and analyze first-semester academic profiles. Improved held-out macro F1 from 0.553 to 0.668 and achieved 70.6% accuracy with logistic regression.

**Tech:** Python · Pandas · Scikit-learn · Logistic Regression · Random Forest · K-Means · PCA

[View Project](https://github.com/montalvoalan/student-success-prediction)

### 🏀 NBA Shot Probability Modeling

Built an end-to-end sports analytics workflow to estimate NBA shot-make probabilities using logistic regression and CatBoost with season-held-out validation. Evaluated the final workflow on 219,527 shots from the 2024–25 season, achieving a 0.63419 log loss with the selected CatBoost model.

**Tech:** Python · Pandas · NumPy · Scikit-learn · CatBoost · Matplotlib · Seaborn

[View Project](https://github.com/montalvoalan/basketball-shot-probability-modeling)

### 🏥 Hospital Operations & Patient Care Analysis

Built an end-to-end hospital operations analysis in Microsoft Excel, using a relational data model and interactive dashboard to analyze 27,891 encounters, 974 patients, $101.5M in claim costs, and 47,701 procedure records.

**Tech:** Excel · Power Query · Power Pivot · DAX · PivotTables · PivotCharts · Advanced Excel Formulas
